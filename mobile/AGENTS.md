# mobile — KronTerm for iPhone (Labs)

**Parent:** `../AGENTS.md`

## OVERVIEW

iPhone Labs client: React 19 + Vite + Capacitor 8 + TypeScript. Opens into KronosChamber and connects to a managed host or an explicitly paired computer. Separate app from the core desktop build — see `README.md` for the implemented slice and phase boundaries.

## STRUCTURE

- `src/` — React app (`app.tsx`, `main.tsx`, `components/`, `lib/`)
- `host/` — Node phone bridge: `kronlink-host.mjs`, `phoneagent-adapter.mjs` (+ `node --test` tests)
- `plugins/` — `local-shell` Capacitor plugin
- `ios/` — Xcode project (generated by Capacitor sync)

## COMMANDS

```bash
npm --prefix mobile run dev          # Vite dev server (host 0.0.0.0)
npm --prefix mobile run build        # tsc --noEmit + vite build
npm --prefix mobile test             # Vitest suite
npm --prefix mobile run test:host    # node --test host/*.test.mjs
npm --prefix mobile run ios:sync     # build + cap sync ios
npm --prefix mobile run host         # run the phone bridge host
```

## NOTES

- Two test runners: vitest for `src/`, `node --test` for `host/` `.mjs` files.
- Styling is plain CSS (`styles.css`, `z-kronterm-mobile.css`) — not Tailwind.
