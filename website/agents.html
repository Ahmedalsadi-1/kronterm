KronosCode: The Brain Behind the Terminal

KronosCode is not just another AI chatbot. It's a first-class citizen of your terminal workspace with the ability to read, write, and control every aspect of your development environment through native MCP tools.

Unlike traditional AI assistants that live in a separate window, KronosCode is embedded into the terminal itself. It sees your output, understands your context, and can manipulate your workspace in real-time.

  • Reads terminal scrollback and understands command output
  • Creates, resizes, and arranges blocks via native tools
  • Browses the web and interacts with pages inside blocks
  • Edits files with intelligent diff previews
  • Brings your own API keys — OpenAI, Claude, Gemini, Ollama
  • Multi-agent orchestration with the Agent Control Protocol
# KronosCode interacting with your workspace agent.create_block({ "type": "terminal", "command": "npm test", "layout": "split-right" }) # Read output and suggest fixes const output = await agent.read_scrollback({ lines: 50 }) const analysis = await agent.analyze_error(output) await agent.apply_fix(analysis.patch) # Navigate the web inside a block await agent.browser_navigate("https://docs.example.com") await agent.browser_screenshot()
