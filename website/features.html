FEATURES

Everything you need to build, debug, and ship.

KronTerm combines terminal, editor, browser, and AI into a single workspace. Here's how each feature works.

WORKSPACE

A workspace, not a window manager.

Drag, drop, resize, and arrange terminals, editors, web views, AI chats, and sandboxes into any layout.

Block System

Replace your tile manager with a flexible block-based workspace that adapts to your flow.

Flexible Layouts

Every block can be dragged, resized, and arranged into any configuration. Split horizontally, vertically, or create complex nested layouts.

  • Replace your tile manager — i3/bspwm flexibility without the config
  • Inline web views for docs and previews — no more alt-tabbing
  • Command blocks to isolate and monitor individual commands
  • One-click full-screen toggle for any block

AI-Native Workspace

KronosCode is built into the terminal itself, not bolted on as an afterthought.

KronosCode AI Engine

The AI reads your output, understands your workspace, and controls every block — all through native MCP tools.

  • Create, close, and arrange blocks on the fly
  • Run terminal commands and read scrollback
  • Browse the web, fill forms, take screenshots — inside a block
  • Edit files with intelligent diff previews and rollback
  • Bring your own keys — OpenAI, Claude, Gemini, or local via Ollama
BROWSER

A browser in every workspace.

Open web views as first-class blocks alongside your terminals.

Inline Browser Blocks

Browse documentation, preview your app, check dashboards — all without leaving KronTerm.

Full Browser Capability

Web views are not iframes — they're full browser blocks with complete interaction capabilities.

  • Full browser blocks with navigation, search, and interaction
  • AI can control the browser — click, type, scrape, screenshot
  • Live preview for dev servers (Vite, Next.js, and more)
  • Multiple browser blocks side by side
