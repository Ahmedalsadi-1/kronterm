WHY KRONTERM

Your terminal, your AI, your workspace.

Everything you need to build, debug, and ship — without leaving the terminal.

01

A workspace, not a window manager.

Drag, drop, resize, and arrange terminals, editors, web views, AI chats, and sandboxes into any layout. Every block can full-screen with one click.

  • Replace your tile manager — i3/bspwm flexibility without the config
  • Inline web views for docs and previews — no more alt-tabbing
  • Command blocks to isolate and monitor individual commands
  • One-click full-screen toggle for any block
02

AI-native, not AI-bolted-on.

KronosCode is the AI engine built into the terminal itself. It reads your output, understands your workspace, and controls every block — all through native MCP tools.

  • Create, close, and arrange blocks on the fly
  • Run terminal commands and read scrollback
  • Browse the web, fill forms, take screenshots — inside a block
  • Edit files with intelligent diff previews and rollback
  • Bring your own keys — OpenAI, Claude, Gemini, or local via Ollama
03

A browser in every workspace.

Open web views as first-class blocks alongside your terminals. Browse documentation, preview your app, check dashboards, or scrape data — all without leaving KronTerm.

  • Full browser blocks with navigation, search, and interaction
  • AI can control the browser — click, type, scrape, screenshot
  • Live preview for dev servers (Vite, Next.js, and more)
  • Multiple browser blocks side by side
04

SSH sessions that survive anything.

Your remote connections survive network drops, sleep cycles, and even KronTerm restarts. Automatic reconnection means you never lose your session mid-work.

  • Sessions persist through network interruptions and restarts
  • Built-in graphical editor for remote files
  • Inline previews for markdown, images, CSVs, PDFs
  • Seamless file sync across local and remote hosts via wsh file
05

Sandboxes, right next to your code.

Spin up isolated environments alongside your code — not in a separate tab. Run commands, test scripts, and iterate without leaving your flow.

  • Isolated sandbox blocks with full terminal access
  • Test scripts and commands without polluting your main shell
  • Ideal for prototyping, debugging, and experimentation

AI ENGINE

KronosCode: The Brain Behind the Terminal

KronosCode is not just another AI chatbot. It's a first-class citizen of your terminal workspace with the ability to read, write, and control every aspect of your development environment through native MCP tools.

Unlike traditional AI assistants that live in a separate window, KronosCode is embedded into the terminal itself. It sees your output, understands your context, and can manipulate your workspace in real-time.

  • → Reads terminal scrollback and understands command output
  • → Creates, resizes, and arranges blocks via native tools
  • → Browses the web and interacts with pages inside blocks
  • → Edits files with intelligent diff previews and rollback
  • → Brings your own keys — OpenAI, Claude, Gemini, Ollama
  • → Multi-agent orchestration with the Agent Control Protocol
# KronosCode interacting with your workspace agent.create_block({ "type": "terminal", "command": "npm test", "layout": "split-right" }) # Read output and suggest fixes const output = await agent.read_scrollback({ lines: 50 }) const analysis = await agent.analyze_error(output) await agent.apply_fix(analysis.patch) # Navigate the web inside a block await agent.browser_navigate("https://docs.example.com") await agent.browser_screenshot()
