# KronTerm Visual Stories

Fifteen polished pixel-art scenes expand the KronTerm pet from a mascot into a guide for the complete product. The built-in image generator created one distinct final image per prompt using these strict references:

- `website/public/assets/product/kronterm-pet-pose1.png`: character identity and proportions.
- `website/public/assets/product/kronterm-homepage.png`: real product layout and surface vocabulary.
- `website/public/assets/generated/finale-pet.webp`: established notebook/pixel-art finish.

All prompts required the same white robotic cat, charcoal screen face, crisp chunky pixels, abstract interface marks with no readable text, the navy/cream/cyan/red/yellow field-guide palette, and no logos, watermark, duplicate characters, extra limbs, painterly rendering, photorealism, or 3D rendering.
