# Generated Website Illustration Sources

The built-in image generator created the original three transparent illustrations and a fifteen-image visual-story collection that make the KronTerm field-guide homepage feel authored and product-specific. Source PNGs and intermediate candidates live here; only optimized WebP files and the selected film poster are copied to `website/public/assets/generated/`.

## Prompt set

All prompts used the existing white robotic cat pet as a strict character reference and requested crisp, deliberately stepped pixel art, a transparent-ready solid chroma background, the site's cream-paper/navy/cyan/yellow/red palette, no readable text, no logos, no watermark, and no painterly or 3D treatment.

- **Workflow orbit:** a wide transparent composition with the pet moving through connected terminal, browser, and notebook/app cards, yellow dotted paths, small bookmark tabs, and sparse pixel sparkles; clear silhouettes with generous negative space for placement over the hero product stage.
- **Blueprint pet:** the pet standing behind an unfolded technical field map containing tiny terminal, browser, file, agent, and cube symbols connected by cyan blueprint lines, plus a small volume bookmark.
- **Finale pet:** the pet planting a red flag on three stacked notebook/workspace layers containing a terminal card, browser card, and connected cyan workflow path.

The final workflow asset also received a small deterministic color cleanup before chroma removal so its pale status rows remain visible against transparency.

The full fifteen-image visual-story prompt set and output inventory are documented in `visual-stories/README.md`.
