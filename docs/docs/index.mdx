# Welcome to KronTerm

KronTerm is a persistent developer workspace where terminals, browsers, files, previews, remote sessions, isolated Linux
desktops, native applications, and AI agents stay visible together. KronosCode can work from the same terminal output,
browser state, files, diffs, and task evidence that you see.

KronTerm is currently a macOS private beta. Windows and Linux builds remain under evaluation. The optional voice engine is
experimental, and the iPhone client is a Labs project.

[Request private-beta access](https://www.kronterm.dev/download) or start with [Getting Started](./gettingstarted).

## The operating model

KronTerm separates actions by surface. Terminal commands, browser interaction, native desktop control, remote hosts, and
sandbox actions use distinct routes. Sensitive work can pause for approval, and the UI keeps commands, diffs, screenshots,
tool state, and recovery information visible.

The desktop offers three presentations over the same workspace:

- **Widgets:** resizable tiled splits.
- **Tabs:** focused widgets in a browser-style tab strip with pane splitting.
- **Canvas:** a freeform, pan-and-zoom workspace for live widgets, notes, diagrams, and agent task/evidence cards.
